# TCF-142 — Django Backend and PostgreSQL Integration

## 1. Test Objective

Verify that the Django backend is configured correctly, connects to the existing PostgreSQL database, and can retrieve café and amenity data without modifying the database schema.

## 2. Test Environment

- Operating system: Ubuntu (WSL)
- Python: 3.12.3
- PostgreSQL: 16.15
- Backend framework: Django 5.2
- Database: `tbilisi_cafe_finder`
- Database user: `tcf_app`

## 3. Test Cases

### TC-01: Django System Check

**Command:**
```bash
python manage.py check
```

**Expected result:** Django reports no system configuration issues.

**Status:** Passed.

### TC-02: PostgreSQL Connection

**Method:** Execute a SQL query through Django's database connection.

```python
from django.db import connection

with connection.cursor() as cursor:
    cursor.execute("SELECT COUNT(*) FROM cafes;")
    print(cursor.fetchone()[0])
```

**Expected result:** `20`

**Actual result:** `20`

**Status:** Passed.

### TC-03: Django ORM Model Integration

**Method:** Query the existing PostgreSQL tables through Django models.

### TC-04: Café–Amenity Relationship

**Method:** Retrieve amenities associated with Vake Corner.

```python
cafe = Cafes.objects.get(name="Vake Corner")

for relationship in CafeAmenities.objects.filter(cafe=cafe):
    print(relationship.amenity.name)
```

**Expected and actual result:**
- Wi-Fi
- Quiet Atmosphere
- Outdoor Seating
- Pet Friendly

**Status:** Passed.
